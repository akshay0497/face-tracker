# 👁️‍🗨️ akshay0497-face-tracker

**akshay0497-face-tracker** is a modern web-based face tracking and employee attendance system. It allows users to capture photos using their webcam to register and track attendance for employees. Built with a fast and efficient tech stack — **React**, **TypeScript**, **Vite**, and **Tailwind CSS** — the app is designed to be performant, intuitive, and extendable.

## ✨ Features

- 📷 Webcam-based employee photo capture
- 🧑‍💼 Register, view, and delete employee records
- 🕒 Capture and store attendance with photo verification
- 📊 Dashboard with key statistics
- 🔍 Search and paginate employee and attendance data
- 💾 Offline-first with IndexedDB storage
- ♻️ Modular, reusable React components

## ⚙️ Tech Stack

- React + TypeScript
- Tailwind CSS
- Vite
- IndexedDB
- HTML5 Web APIs (Camera access)

## 🚀 Getting Started

### 1. Clone the Repository

```bash
git clone https://github.com/yourusername/akshay0497-face-tracker.git
cd akshay0497-face-tracker
````

### 2. Install Dependencies

```bash
npm install
```

### 3. Start the Development Server

```bash
npm run dev
```

### 4. Build for Production

```bash
npm run build
```

## 🧪 Usage

* Go to Register Employee page, fill form and capture image.
* Navigate to Attendance, select employee and mark attendance using photo.
* Dashboard displays current attendance and stats.
* View or manage employee records via View Employees page.
